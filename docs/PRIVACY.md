# Privacy

UniversalDocs has no login, no mandatory backend, and no automatic document upload. A user chooses a connected device folder or private browser storage. The application exposes permissions in understandable language and shares files only after an explicit share/download action.

Private browser storage belongs to the browser and can be cleared outside the app; it is not a user-visible operating-system folder. See the plain-language root [privacy notice](../PRIVACY.md) for the full statement.
