# Roadmap

## Completed foundation

The project has a responsive PWA shell, local storage abstraction, folder permission recovery, OPFS/IndexedDB private fallback, local index rebuilding, file import/search/filter/list-grid UI, basic format viewers, local text editing as save-copy, deterministic fact extraction, photo capture, video recording, and image-to-PDF conversion.

## Next engineering milestones

The next logical work is to harden the local scanner with manual corner adjustment and perspective correction, then add page-oriented PDF operations. Later milestones evaluate lazy local OCR and translation models, office adapters, backup/restore archives, ID scanning, ID-photo layout, and further language coverage.

No feature should move from this roadmap into the interface until it can run locally or clearly explains its optional model-download requirement.
